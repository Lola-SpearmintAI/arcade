# Arcade

A collection of browser games written in vanilla HTML, CSS, and JavaScript. Each game runs independently in its own folder with its own styles and scripts. No frameworks, no build tools, no dependencies.

**Games:**
- Flappy Bird — fly through pipes, spacebar to jump
- Snake — eat food, avoid walls and yourself
- Breakout — smash bricks with a bouncing ball

Play them locally or host the folder anywhere — every asset is included, nothing loads from the network.
